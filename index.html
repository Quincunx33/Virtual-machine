Frequently Asked Questions

Everything you need to know about running Linux, Windows, and DOS virtual machines directly inside your browser.

What is WebVM and how does it run an operating system in a browser?

WebVM is a client-side x86 PC emulator powered by libv86 and WebAssembly. It compiles x86 CPU instructions directly inside your browser so you can boot and run real operating systems without installing virtual machine software or relying on cloud servers.

Which operating systems and disk image formats are supported?

WebVM supports lightweight Linux distributions such as Alpine Linux, TinyCore, and Arch Linux, as well as FreeDOS and classic Windows environments. You can boot from CD-ROM (.iso), floppy (.img, .bin), and hard disk images (.img, .raw), or configure direct Linux kernel booting with bzImage and initrd.

Are my files, virtual hard disks, and snapshots private?

Yes. All virtual machine execution happens locally on your device, and your configurations, virtual hard disks, and RAM state snapshots are stored inside your browser's local IndexedDB storage. No disk images or personal data are uploaded to any server.

Can I use WebVM offline or on mobile and tablet devices?

Yes. You can enable Offline Caching in the dashboard to precache the WebAssembly core and assets via Service Worker for offline use. On phones and tablets, WebVM includes a touch-friendly virtual keyboard and an Assistive Touch menu for mouse clicks, Ctrl+Alt+Del, fullscreen, and state saving.

How much RAM should I allocate to a virtual machine?

For DOS and lightweight Linux distros like TinyCore or Alpine, 64 MB to 128 MB of RAM works reliably. WebVM automatically inspects your host device memory to set a safe upper limit and offers a Potato Mode CPU profile for lower-spec hardware.

Does WebVM support saving state and continuing later?

Yes. While a virtual machine is running, you can save a complete RAM snapshot locally or export and import state files (.bin, .v86state) to resume your session exactly where you left off.
